# Primeiros passos
Antes de iniciar com a automação, precisamos que sua máquina esteja configurada. 
A forma mais rápida para isso atualmente é o instalador do ProtonClient.

#### Ações realizadas pelo Installer:

-  Verificação JDK 1.8+
-  Verificação Git Library
-  Verificação NodeJS
-  Maven | ADB
-  Appium Server
-  Criação arquivo para Download dependências Maven
-  Variáveis de ambiente

> **Documentação:** [Proton Client Installer - (slite.com)](https://atomicsolutions.slite.com/app/channels/2Nn6QWiWy9/notes/bT7FL4NDjV)
